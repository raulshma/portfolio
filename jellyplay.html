Self-hosted media, without a compromised client.

JellyPlay is built from the ground up in Kotlin and Jetpack Compose for people who run a Jellyfin server and expect a genuinely native experience—not a web wrapper.

The app adapts across phones, tablets, foldables, Android TV, and Fire TV while keeping a media library, playback controls, and server tools coherent across form factors.

A full media client, not just a player.

Playback depth, self-hosted control, and platform-aware UI are treated as connected parts of the same product experience.

01

One adaptive interface

Responsive layouts and dedicated TV interaction patterns carry the experience across mobile, tablet, foldable, and big-screen devices.

02

Playback with options

ExoPlayer, libmpv, and LibVLC provide multiple playback engines alongside casting, subtitles, HDR, picture-in-picture, and offline downloads.

03

Beyond the library

Music with synced lyrics, SyncPlay watch parties, Jellyseerr requests, server administration, and multi-server support extend the core viewing flow.
